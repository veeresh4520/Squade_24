## Task
At a campus election desk, the program is used for a short beginner exercise. Make it follow the stated rule for the supplied values. Keep the solution within basic Java syntax, variables, conditions, loops, arrays, strings, and simple methods.

## Expected output
```text

2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
```
